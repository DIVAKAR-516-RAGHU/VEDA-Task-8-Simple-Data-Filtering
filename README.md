# VEDA AI & ML Track – Task 8: Simple Data Filtering

## 📌 Overview

This project is part of the **VEDA AI & ML Track – Task 8**.  
The objective is to understand and implement **data filtering using Python and Pandas**.

Student records are created and filtered based on different conditions such as marks, age, and department.

## 🎯 Objectives

- Create and manage student records using Python dictionaries.
- Filter students based on marks.
- Filter students based on age.
- Filter students based on department.
- Apply multiple filtering conditions.
- Convert student records into a Pandas DataFrame.
- Perform Boolean filtering using Pandas.
- Understand the difference between filtering and sorting.

## 🛠️ Technologies Used

- Python
- Pandas
- Jupyter Notebook

## 📊 Operations Performed

### 1. Filter by Marks

Students scoring **85 or above** are selected.

### 2. Filter by Age

Students aged **20 or below** are selected.

### 3. Filter by Department

Students belonging to the **ECE department** are selected.

### 4. Multiple Conditions

ECE students with marks **80 or above** are selected.

### 5. Pandas DataFrame

The student records are converted into a Pandas DataFrame for structured data analysis.

### 6. Boolean Filtering

Multiple conditions are applied using:

- `&` for AND
- `|` for OR

### 7. Sorting

Filtered student records are sorted based on marks in descending order.
